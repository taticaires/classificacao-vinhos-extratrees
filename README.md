# Classificação de Vinhos com Machine Learning

Projeto acadêmico em Python que utiliza análise exploratória de dados e o algoritmo **ExtraTreesClassifier** para classificar vinhos em tintos e brancos a partir de características físico-químicas.

## Objetivos

- Explorar uma base tabular com Pandas.
- Visualizar a distribuição das notas de qualidade.
- Preparar variáveis para Machine Learning.
- Treinar e avaliar um classificador com Scikit-learn.

## Tecnologias

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## Como executar

1. Abra `Classificacao_de_Vinhos_ExtraTrees.ipynb` no Google Colab ou Jupyter Notebook.
2. Execute as células em ordem.
3. O notebook baixa automaticamente os arquivos originais do UCI Machine Learning Repository. É necessário acesso à internet na primeira etapa.

## Base de dados

A base reúne 6.497 amostras de vinhos verdes portugueses (1.599 tintos e 4.898 brancos), com medições físico-químicas e notas de qualidade. Os dados originais são disponibilizados separadamente para vinhos tintos e brancos.

**Fonte:** Cortez, P. et al. (2009). *Wine Quality*. UCI Machine Learning Repository. https://doi.org/10.24432/C56S3T
